# Hosted synthetic sandbox login

Separate Render backend/frontend and a separate Neon branch cloned from the synthetic demonstration database. The public demo remains read-only. APP_ENV=sandbox requires a server-side verifier; no real identity mode, MFA, storage, consent, admin or production gates are changed. One fictional specialist account, fixed organization, opaque random tokens hashed in PostgreSQL, four-hour maximum, 15-minute idle cutoff, database-backed login throttle, logout revocation. Profile and measurement writes only, scoped to the existing fictional operator's grants. No persistent browser credentials. No real personal data. Scenario persistence and server reports remain unavailable. The sandbox access-event table records write outcomes without sensitive payloads. This is a separate prototype access mode, not an implementation of the production identity contract. Integration and deployment acceptance remain required.
