# F7 — Verificación de comprobantes Ed25519 en el navegador

Entrega complementaria al PR #91. Permite verificar un PDF o CSV ficticio que ya está guardado, sin volver a exportarlo ni instalar herramientas. En la analítica privada de un expediente ficticio se abre «Verificar firma de un informe guardado» y se seleccionan tres archivos: el informe original, su comprobante JSON y la clave pública de confianza (32 bytes crudos Ed25519, obtenida independientemente). No se transmite ni persiste ninguno de los tres archivos. No se necesitan credenciales o acceso al servidor durante la operación criptográfica una vez cargado el panel.

El verificador valida los límites de tamaño, nombre, metadatos, fecha UTC, huellas SHA-256 de contenido y clave, campos JSON no ambiguos y la firma Ed25519 sobre el manifiesto canónico. Utiliza Web Crypto; un navegador incompatible falla cerrado. Cambiar la selección invalida resultados anteriores. No se obtiene una clave de confianza del comprobante ni de la misma respuesta de exportación. El resultado demuestra correspondencia criptográfica con la clave seleccionada, no identidad legal, vigencia de credenciales, sello de tiempo externo, exactitud clínica ni custodia.

Regresiones: firmas reales PDF y CSV con claves efímeras generadas por Node; sustitución de clave, alteración de bytes/metadatos, campos duplicados, fecha imposible, límites de lectura y navegador sin Ed25519; controles React con selección obligatoria de tres archivos y limpieza de resultados. Pendiente CI integral y aceptación independiente. No activa producción ni configura claves reales.
